# Which board do I have?

Every board has its **model and revision printed on it**, next to the Kulp Lights logo
(for example `K16-Max v4.1.0`). FPP also shows the model on its **Status** page and under
*Help → About*.

To tell them apart at a glance:

| What you see | Board |
|---|---|
| **8** green pixel plugs, mini-blade fuses along the bottom edge | [K8-Pro](../boards/k8-pro.md) |
| **8** green pixel plugs, no fuses | [K8-Max](../boards/k8-max.md) |
| **8** green pixel plugs on a small (74 × 97 mm) board, **3** RJ45s, no Ethernet jack, a 24-pin header on the left edge | [K8-PB](../boards/k8-pb.md) |
| **4** green pixel plugs in one row on a small (71 × 67 mm) board, no RJ45 jacks | [K4-PB](../boards/k4-pb.md) |
| **16** pixel plugs with fuses, **4** port RJ45s, one `DMX` jack | [K16](../boards/k16.md) |
| **16** pixel plugs with fuses, **8** port RJ45s, `DMX1`/`DMX2` | [K16-Pro](../boards/k16-pro.md) |
| **16** pixel plugs, no fuses, **8** port RJ45s | [K16-Max](../boards/k16-max.md) |
| **32** pixel plugs with fuses, **4** port RJ45s, one `DMX` jack | [K32](../boards/k32.md) |
| **32** pixel plugs with fuses, **8** port RJ45s, `DMX1`/`DMX2` | [K32-Pro](../boards/k32-pro.md) |
| **32** pixel plugs, no fuses, **8** port RJ45s | [K32-Max](../boards/k32-max.md) |
| **6** ribbon-cable (HUB75) headers along the bottom edge, no Ethernet jack | [PocketScroller v2](../boards/pocketscroller-v2.md) |
| **8** ribbon-cable (HUB75) headers marked *Output 1–8* | [PocketScroller v3](../boards/pocketscroller-v3.md) |
| **16** ribbon-cable (HUB75) headers in two rows, *Output 1–16* | [PocketScroller-16](../boards/pocketscroller-16.md) |
