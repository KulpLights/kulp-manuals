    Boards¶

    All of the boards use the same building blocks, so each board page is short and links to the shared Hardware chapters for details.

    Which model line?¶

    • Base (K16, K32): the most outputs for the money. Fused ports and send-only differential.
    • Pro: adds two-way differential for Falcon V5 receivers, audio, a second DMX output, three USB ports, a fan header and expansion I/O. Bank power switching (K8-Pro, and K16-Pro/K32-Pro from v4.1).
    • Max: everything in Pro, plus an eFuse on every port. FPP can switch each port and read its current, and a short is cut in microseconds and reported in FPP instead of blowing a fuse.

    All three are hats for the Raspberry Pi, which provides the network and USB ports. FPP drives their pixel ports with its DPIPixels output: up to 1600 pixels per string, with smart receivers in v1 or v2 mode. See Raspberry Pi.

    Displays & add-ons¶

    The BBB-OLED and Pi-OLED add a status display, menu buttons, a real-time clock and a temperature sensor to a BeagleBone Black or Raspberry Pi running FPP, with no outputs of their own. The PiOLED 3.0 also adds a high-quality line-level audio output.

    All boards¶

    All of them run FPP. The boards in the PocketBeagle 2 section need a PocketBeagle 2; the K4-PB, K40D-PB and PocketScroller v2 also work with the original PocketBeagle 1. See PocketBeagle 2, BeagleBone Black and Raspberry Pi.
